# 术语表

本文件是工作区术语表，供阅读本 skill、写流水与记忆时统一用词。在这里只解释概念。操作步骤见 SKILL.md 执行部署一节，落点见 operating-rules.md 产物归口一节，记忆规则见 operating-rules.md 记忆与账本一节，验收见 acceptance.md。同名术语用于其他含义时，先核对。

## 部署与流转

**落地**：一次性创建工作区骨架并纳入版本控制，全生命周期只发生一次。
_Avoid_：转移，拷贝

**抽取**：首次落地时，把该设备上 agent 工具已产生的可读资料收进待判断区，原物不动。
_Avoid_：导入，同步

**接入**：新 agent 读懂本 skill 并按本 skill 写入，不包含收编旧资料。
_Avoid_：注册，上线

**闭环**：输入、输出、沉淀、归档四段都留下可追溯指针。
_Avoid_：归档（归档只是闭环的一段）

## 记录与记忆

**指针**：一段流转留下的最小记录，含四项：来源、去向、时间、当前状态。只追加状态，不回改历史记录。
_Avoid_：链接，索引

**草稿箱**：agent 自动写出的沉淀候选存放处。用户分拣前不构成权威，agent 不把它当作记忆读取。
_Avoid_：待办，收件箱

**分拣**：用户对草稿箱候选逐条判定批准、否决或暂缓。批准是晋升进长期记忆、知识库或规则的唯一触发。
_Avoid_：审核（分拣是用户的判定动作，不是流程关卡）

**三层**：内核层（规则、记忆、清单，小，可版本化）；资产层（项目证据报告与数字资产，清单管理）；机器层（工具本体、应用、缓存，不进收口目录）。
_Avoid_：三级目录

## 维护规则

- 术语以本 skill 已定规则为依据。存在争议时保留待确认状态，不合并含义不同的对象。
- `_Avoid_` 标的是写作时不推荐替代使用的称呼。旧资料使用这些字样时，仍需按上下文辨别它指的是哪个对象或动作。
- 在这里解释概念；流程、落点和验收分别见 SKILL.md 与 operating-rules.md、acceptance.md。

## 誊抄规则

写工作区根 `CONTEXT.md` 时照抄本文件的分组、条目与维护规则，标题写 `# CONTEXT.md`，分组降为二级标题，导语中的“本文件”保持为“本文件”，节号指向本 skill 原文。不写实现。后续新增术语按同一格式追加，先有定义与 `_Avoid_` 再使用。
